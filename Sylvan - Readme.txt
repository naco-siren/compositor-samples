SYLVAN — A forest within.

Current revision: continuous foliage-to-back contour + clearly visible foggy forest background.
3200 × 2000 px / sRGB

Open Sylvan - Double Exposure.comp in Compositor.
The 08 · TYPOGRAPHY folder toggles the poster copy on and off.
For a clean export, hide that folder and select a visible photo layer before Export PNG.

Foreground:
The original portrait and the continuous tree retain the accepted geometry: 5% reduction about anchor (2500, 240), 7° counterclockwise tilt. Both tree passes have identical pixels and transforms. The face/cheek/jaw transition is retained. The shoulder keeps real cloth and skin detail. Portrait and both tree passes now share one continuous curved lower exit; the exterior foliage no longer switches to a separate hard boundary at the portrait silhouette. Leaf contours remain visible across the back transition. A local density curve preserves skin and cloth detail.

Background controls:
01c · Forest / WARM mist is visible by default.
01b · Forest / COOL alternative is hidden; enable only one forest at a time.
Each forest has 78% layer opacity plus a mask that quiets the typography area.
01d · Forest light is an editable background-only Curves layer; it retains visible forest midtones while opening the fog and keeping the foreground dominant.
02c · Shoulder contour is an editable local Curves layer for skin and cloth density.
