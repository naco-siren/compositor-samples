WINDOW GUEST / 窗外有客 — Compositor Study 02

3200 × 2000 px / sRGB / 144 ppi

An oversized bird peers through a real old-town window. The photographed feet remain attached to their original branch; the foreground window frame masks the bird and branch, while the roofs establish the deliberately impossible scale.

Editable structure:
Outside — original town photograph and cool daylight curve
Visitor — original bird photograph, detailed bird/branch mask, daylight curve and a soft lower-body shade curve
Window — foreground window photograph, aperture mask and room curve
Typography — five editable text layers using Baskerville and Helvetica

The project embeds its source pixels and masks. It can be opened without the Assets folder. Hide Typography for artwork without lettering. Select the bird image thumbnail to move it; select its mask thumbnail to refine the cutout. Save the .comp before checking Git: export alone does not save project edits.

The window source was reduced to 4096 × 3072 for the embedded layers; the bird source retains its original 4808 × 6010 pixels.

The bird's starting mask uses the same local Apple Vision foreground-selection model as Compositor's Remove Background tool. The original branch and claw openings were refined separately. All scene pixels come from the two photographs; the generated concept sketch is not used as a layer.
